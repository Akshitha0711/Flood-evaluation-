#  Flood Evacuation Route Optimizer

A Machine Learning + GIS based project to find the safest 
evacuation routes during flood scenarios.

## Problem Statement
During floods, people need the safest route to evacuate — 
not just the shortest. This project predicts flood risk on 
roads and finds the safest path to safety.

## Progress
- ✅ Step 1: Flood Risk Prediction Model (R2: 0.729)
- ✅ Step 2: Road Network Loading (Indiranagar, Bangalore)
- ✅ Step 3: Safe Route Visualization (Blue vs Green route)
- 🔄 Step 4: Interactive Web App (in progress)

## Tech Stack
| Tool | Purpose |
|------|---------|
| Python | Core language |
| Scikit-learn | Random Forest ML model |
| Pandas | Data processing |
| OSMnx | Road network (GIS) |
| NetworkX | Route optimization |
| Streamlit | Web app UI |
| Folium | Interactive maps |

##  Dataset
- 50,000 records
- 20 flood risk features
- Target: FloodProbability (0 to 1)

##  Output
- Feature importance chart
- Actual vs Predicted flood probability
- Real road network of Indiranagar, Bangalore
- Safe evacuation route vs normal shortest route
